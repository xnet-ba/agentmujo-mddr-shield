# clickfix-phishing-drill


## Purpose
Generate safe, measurable social-engineering drill scenarios (ClickFix dialogs, QR-phishing mail) to train staff and test detection (MDDR 2026 takeaway 3: people remain the most exploited initial-access path).

## Guidance
- Work only within the authorized scope. Drills are simulations for training — never send real phishing, never collect real credentials.
- Input: target group + difficulty (basic/intermediate/advanced). Output: scenario script + delivery notes + scoring sheet.
- Base scenarios on observed TTPs: ClickFix-style fake-fix dialogs, AI-personalized spear-phishing lures, QR-code payloads, SVG/DOC attachments (MDDR 2026 cybercrime chapter: >100M phishing mails observed, QR-phishing wave 145M+).
- Every drill must include: what the victim sees, which red flags are embedded, how to report, and a debrief template. No-credential rule: the drill ends at the click/report decision — no fake login pages harvesting input.
- Sending any drill to real recipients requires explicit written approval from the requester; the default deliverable is the scenario package, not the send.
- Measure: report rate and report speed, not just click rate. Track improvement across repeated drills.
- Use your core planning/research skills for planning, research, debugging, verification, and reporting.

## Expected Output
Scenario package (script + red-flag key), scoring sheet template, debrief agenda, and remaining uncertainties. No live send without approval.
